# Employee, Customer & Sales Management System

## The application Features:
- Add employees, customers, and sales.
- Store records using a single reusable binary tree template.
- Serialize records into a byte array.
- Save serialized data to a binary file named Data.bin.
- Read and deserialize saved data.
- Search for an employee by name and generate a sales report.
- Automatically load data at startup and save data on normal program exit.
